# ลืมรหัสผ่านแอดมิน — ตั้งใหม่เองใน 2 นาที

หน้าหลังบ้าน (`admin.html`) ล็อกอินด้วย Supabase Auth
โปรเจกต์นี้ **ยังไม่ได้ตั้ง SMTP** จึงยังส่งอีเมล "รีเซ็ตรหัสผ่าน" ไม่ได้
วิธีที่แน่นอนที่สุดคือตั้งรหัสใหม่จาก SQL Editor ของ Supabase เอง

> รหัสผ่านที่พิมพ์ในขั้นตอนนี้ไม่ผ่านใครเลย — พิมพ์ในหน้าเว็บของ Supabase ตัวเอง

## ขั้นตอน

1. เปิด <https://supabase.com/dashboard/project/apjgwbwdzkxadbcutuxt/sql/new>
2. วางคำสั่งข้างล่างลงไป **แล้วแทนที่ `ใส่รหัสใหม่ที่นี่` ด้วยรหัสที่อยากใช้**
   (อย่างน้อย 8 ตัวอักษร ห้ามมีเครื่องหมาย `'` ปนอยู่)

   ```sql
   update auth.users
   set    encrypted_password = extensions.crypt('ใส่รหัสใหม่ที่นี่', extensions.gen_salt('bf', 10)),
          updated_at         = now()
   where  email = 'fw89s6gqvd@privaterelay.appleid.com';
   ```

3. กด **Run** — ต้องขึ้น `Success. 1 row`
4. เปิดหน้าหลังบ้าน ล็อกอินด้วยรหัสใหม่ได้ทันที
5. **ลบคำสั่งออกจาก SQL Editor** เพื่อไม่ให้รหัสค้างอยู่ในประวัติคำสั่ง

## ครั้งต่อไปไม่ต้องทำแบบนี้

ล็อกอินเข้าไปแล้วกด **ไอคอนกุญแจ** มุมขวาบน → เปลี่ยนรหัสผ่านได้ในแอปเลย

## ทำไมคำสั่งนี้ใช้ได้

Supabase (GoTrue) เก็บรหัสผ่านเป็น bcrypt ใน `auth.users.encrypted_password`
`extensions.crypt(..., gen_salt('bf', 10))` สร้างแฮชแบบเดียวกัน (`$2a$10$…`) ที่ระบบล็อกอินตรวจผ่าน
